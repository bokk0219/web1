# 2manythings

> 많은 일도, 차곡차곡.

해야 할 일을 관리하는 앱이 아니라, 내가 실제로 한 일을 기록하고
그 기록에서 나만의 생활 패턴을 발견하는 앱.

## 핵심 흐름

했다 → 기록한다 → 쌓인다 → 나의 패턴을 발견한다

- 항목(예: 침구 교체, 손톱 깎기)을 만들고, 할 때마다 날짜만 기록
- 항목별로 필요하면 가격/수량/이유 같은 선택 정보도 남길 수 있음
- 기록이 2건 이상 쌓이면 간격(일 수), 평균/최단/최장 간격을 자동 계산
- 주기를 미리 정하지 않고, 실제 기록에서 패턴을 발견하는 것이 목표

## MVP 기능

1. 항목 만들기
2. 항목별 기록 추가
3. 최근 기록 보기 (홈 화면)
4. 날짜별 기록 확인 (항목 상세)
5. 기록 간격 자동 계산
6. 평균/최단/최장 간격 계산
7. 항목별 통계 보기
8. 첫 실행 스플래시 화면

## 기술 스택

- React + TypeScript + Vite
- Tailwind CSS (베이지/브라운/그레이 톤)
- 데이터는 브라우저 `localStorage`에 저장 (별도 서버 없음)

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
npm run preview  # 빌드 결과 미리보기
```

# 띡! 쇼핑 (`ddik/`)

> 가격 비교도, 카드 계산도, 띡!

신한카드 Deep ECO · 네이버 현대카드 Edition3 기준으로 판매처별 실질 구매 비용을 비교하는 개인용 웹 앱.
같은 빌드에 별도 페이지로 들어 있으며 배포 주소는 `/web1/ddik/`.

- 비교 대상 쇼핑몰: 네이버플러스 스토어 · G마켓 · 11번가
- 카드 조건(전월 실적 충족, 멤버십 회원)은 한 번만 정해 두고, 이번 달 한도 사용액은 선택 입력
- 네이버 가격비교·G마켓·11번가 검색 결과 화면을 복사해 붙여넣으면 상품명·가격·배송비·용량을 읽어 쇼핑몰별 최저(100ml당) 후보를 자동 선택 (`ddik/src/parse.ts`)
- 「띡」 북마크(북마크릿): 쇼핑몰 화면에서 누르면 화면 내용을 정리해 `postMessage`로 앱에 전달 (`ddik/src/collect.ts`, `ddik/src/inbox.ts`). 휴대폰처럼 전체 선택이 안 되는 곳용
- 상품 링크로 판매처 자동 인식, 가격·배송비·쿠폰은 직접 입력 (쇼핑몰이 외부 페이지 읽기를 막아 정적 웹 앱에서는 가격 자동 수집 불가)
- 카드 혜택 기준은 `ddik/src/cards.ts` 한 곳에서 관리 (기준일·출처 표시)
- 계산에 쓴 가정은 결과 화면에 함께 표시
- 카드 설정·최근 비교는 브라우저 `localStorage`에만 저장, 카드 번호 등은 받지 않음
