# 나는 이렇게 산다

해야 할 일을 관리하는 앱이 아니라, 내가 실제로 한 일을 기록하고
그 기록에서 나만의 생활 패턴을 발견하는 앱.

## 핵심 흐름

했다 → 기록한다 → 쌓인다 → 나의 패턴을 발견한다

- 항목(예: 침구 교체, 손톱 깎기)을 만들고, 할 때마다 날짜만 기록
- 항목별로 필요하면 가격/수량/이유 같은 선택 정보도 남길 수 있음
- 기록이 2건 이상 쌓이면 간격(일 수), 평균/최단/최장 간격을 자동 계산
- 주기를 미리 정하지 않고, 실제 기록에서 패턴을 발견하는 것이 목표

## MVP 기능

1. 항목 만들기
2. 항목별 기록 추가
3. 최근 기록 보기 (홈 화면)
4. 날짜별 기록 확인 (항목 상세)
5. 기록 간격 자동 계산
6. 평균/최단/최장 간격 계산
7. 항목별 통계 보기
8. 첫 실행 스플래시 화면

## 기술 스택

- React + TypeScript + Vite
- Tailwind CSS (베이지/브라운/그레이 톤)
- 데이터는 브라우저 `localStorage`에 저장 (별도 서버 없음)

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
npm run preview  # 빌드 결과 미리보기
```
